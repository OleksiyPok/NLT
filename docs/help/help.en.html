Program Purpose

Number Listening Trainer is designed for learning numbers in foreign languages and for training listening comprehension.

The program generates a set of random numbers, says them aloud in the selected language with the selected voice, and repeats the exercise as many times as you need. You choose the length of the numbers, how many of them there are, how fast they are spoken and how long the pauses are.

An optional delay between showing a number and saying it turns the exercise into a game: you can see the number first and say it yourself before the program does, or hear the number first and picture it before it appears on the screen.

The interface is available in 13 languages: العربية, Čeština, Deutsch, English, Español, Français, Italiano, Nederlands, Polski, Português, Русский, Türkçe, Українська.

Main screen

  1. Information: opens this window.
  2. Settings: opens the settings window (see "Settings").
  3. Mode: colour mode of the interface: Contrast, Normal, Evening or Night. Each press switches to the next mode.
  4. Number fields: the numbers of the exercise.
  5. Repeats left: how many times the exercise is still to be played.
  6. Rnd: generates new random numbers.
  7. Start / Pause / Continue: starts the exercise, pauses it and continues it.
  8. Reset: returns the exercise to the beginning (available when it is paused).
  9. Playback and display controls: Speed, Interval, Fullscreen, Delay mode, Delay, Digit length, Count and Repeat. They are the same controls as in the settings window and are described in "Settings".

How to use

  1. Choose the language and the voice in the settings.
  2. Set the length of the numbers, their count and the number of repeats.
  3. Press Rnd to get new numbers, then Start. The number being said is highlighted.
  4. Write down what you hear, or say the number yourself, and compare it with the screen.

Settings

The settings window is opened with the button. It consists of blocks; scrolling takes you from block to block, and a fraction in the corner shows the number of the current block over the total number of blocks. The playback and display controls of the main screen are the same controls and always show the same values. A change is applied at once, even during playback.

Speed and interval

  1. Speed: the speed of the speech, from 0.6 (slow) to 2.0 (fast).
  2. Interval (ms): the pause between the end of one number and the beginning of the next, in milliseconds.

Fullscreen and delay

  1. Fullscreen: Yes shows the current number over the whole screen, No highlights it only inside the exercise area.
  2. Delay mode: No (the number is shown and said at the same time), Visual (the number is said first and shown after the delay) or Audio (the number is shown first and said after the delay).
  3. Delay (sec): the length of the delay, from 1 to 5 seconds.

Numbers

  1. Digit length: the length of the numbers: 1 (units), 2 (up to tens) or 3 (up to hundreds).
  2. Count: how many numbers there are in the exercise.
  3. Repeat: how many times the exercise with the same numbers is played, from 1 to 10.

Language and voice

  1. Language: the language of the speech.
  2. Voice: the voice of your device. The list depends on your device and browser.

Interface, theme and mode

  1. Interface: the language of the program labels.
  2. Theme: the colour palette of the program.
  3. Mode: Contrast (brighter and sharper), Normal, Evening or Night. Night mode is dark and dim, so you can look at the screen calmly in the dark. It works in sync with the Mode button on the main screen.

Reset defaults

  1. Reset defaults (): returns all settings to their original values.

Notes

All settings are saved in your browser and are kept after you close the program.

The help and settings windows are closed with the ✕ button or the Esc key; on a phone, also with the Back button. The F1 key opens this window.

If the language has no voices on your device, install a voice in the system settings.
