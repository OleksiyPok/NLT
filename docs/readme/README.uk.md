# NLT Number Listening Trainer

Це компактний односторінковий додаток, призначений для вивчення чисел іноземними мовами.  
Додаток застосовує метод одночасного аудіального та візуального сприйняття, що забезпечує швидке та ефективне запам'ятовування.

<img src="img/app.png" alt="Зовнішній вигляд застосунку" width="360">

## Можливості

- Читає випадкові числа вголос і підсвічує кожне на екрані, тож ви водночас чуєте й бачите його.
- Оберіть довжину чисел, скільки чисел тренувати й скільки разів повторити серію.
- Налаштуйте швидкість мовлення, паузу між числами, а також мову й голос вашого пристрою.
- Необов’язковий повноекранний режим показує поточне число великим шрифтом (на телефонах увімкнений типово).
- Працює на телефонах і комп’ютерах, 13 мовами інтерфейсу, з 10 кольоровими темами в чотирьох режимах (звичайний, вечірній, нічний, контрастний).

## Налаштування

У вікні налаштувань є швидкість та інтервал, повноекранний режим, довжина чисел, кількість і повтори, мова й голос, мова інтерфейсу, тема й режим, а також скидання до типових значень.
