# NLT Number Listening Trainer

<div dir="rtl">
هذا تطبيق مدمج من صفحة واحدة مخصص لتعلّم الأرقام بلغات أجنبية.  
يعتمد التطبيق طريقة الإدراك السمعي والبصري المتزامن، مما يتيح الحفظ السريع والفعّال.
</div>

<img src="img/app.png" alt="مظهر التطبيق" width="360">

## المزايا

- يقرأ أرقامًا عشوائية بصوت مسموع ويُبرز كل رقم على الشاشة، فتسمعه وتراه في الوقت نفسه.
- اختر عدد خانات الأرقام، وكم رقمًا تتدرّب عليه، وكم مرة تُعاد السلسلة.
- اضبط سرعة الكلام، والفاصل بين الأرقام، ولغة جهازك وصوته.
- يعرض وضع ملء الشاشة الاختياري الرقم الحالي بخط كبير (وهو مفعّل افتراضيًا على الهواتف).
- يعمل على الهواتف والحواسيب، بـ 13 لغة للواجهة، مع 10 سمات لونية في أربعة أوضاع (عادي، مسائي، ليلي، تباين عالٍ).

## الإعدادات

تضم نافذة الإعدادات السرعة والفاصل، وملء الشاشة، وعدد الخانات، والعدد والتكرار، واللغة والصوت، ولغة الواجهة، والسمة والوضع، وإعادة الضبط إلى الإعدادات الافتراضية.
